SOFTWARE ENGINEERING METHODOLOGY

How Capstone Projects Are Structured

During the MCA program, students learn to approach software development systematically—from requirement gathering and UML modeling to database normalization, modular coding, and unit testing.

Phase 1 – Problem Definition & SRS: Preparing Software Requirements Specifications and feasibility analysis.
Phase 2 – System & Database Design: Creating ER diagrams, data flow diagrams (DFDs), and normalized SQL schemas.
Phase 3 – Implementation & Testing: Writing clean, modular code with test cases and documentation.

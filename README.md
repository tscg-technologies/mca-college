# MCA College Website – Premium Multi-Page Demo Website

A modern, technology-focused, fully responsive, multi-page demonstration website designed for an Indian **MCA (Master of Computer Applications)** educational institution.

## 1. Strict Technology Stack
- **HTML5** (Semantic markup, SEO metadata, Open Graph tags, ARIA accessibility attributes)
- **CSS3** (Custom properties, responsive CSS Grid/Flexbox layouts, subtle transitions)
- **Vanilla JavaScript (ES6+)** (Zero external frameworks or backend dependencies; compatible with Hostinger static hosting)

## 2. Brand & Demonstration Compliance
- **Generic Terminology Only**: Uses strictly generic institutional titles (`MCA COLLEGE`, `MCA COLLEGE WEBSITE`, `OUR COLLEGE`, `ABOUT OUR COLLEGE`, `MCA PROGRAM`, `ADMISSIONS`, `PLACEMENTS`, `CAMPUS LIFE`, `CONTACT US`). No real or fictional college or university names are invented.
- **Logo**: Original graduation-cap and technology SVG icon with no embedded brand identity text.
- **Dummy Contact Placeholders**:
  - Phone: `0000000000`
  - Alternative Phone: `0000000000`
  - Email: `demo@example.com`
  - Address: `Plot No. 000, Demo Road, Sample Area, Hyderabad, Telangana – 000000.`
  - Working Hours: `Monday – Saturday, 9:00 AM – 5:00 PM.`
- **Illustrative Disclaimers**: All statistics, placement figures, faculty profiles, student projects, events, testimonials, and admission procedures are clearly labelled as illustrative demonstration content.

## 4. Interactive Vanilla JavaScript Features
1. **Responsive Mobile Navigation**: Smooth toggle, outside-click dismissal, Escape key support, and auto-close on navigation link selection.
2. **Sticky Header & Back-to-Top Button**: Scroll-aware header elevation and smooth scroll-to-top button.
3. **Animated Statistics Counters**: IntersectionObserver-powered number counters for sample academic metrics.
4. **Interactive FAQ Accordion**: Accessible single-open accordion with 9 MCA questions tailored to Indian students.
5. **Project Portfolio Category Filtering**: Filter 8 illustrative MCA software projects by technology category.
6. **Campus Life Lightbox**: Full-screen image modal with captions and keyboard navigation.
7. **Frontend Form Validation**: Validates full name, 10-digit Indian mobile number, email format, graduation details, and learning domain with inline error messages and a frontend-only demo submission alert.
8. **Resilient SVG Placeholder Fallback**: Automatically renders a custom Deep Navy & Electric Blue SVG placeholder if any image asset is unavailable.
